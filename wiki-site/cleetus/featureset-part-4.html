Featureset part 4: streams 35 to 45, client/core rendering modules

How it works

This page covers lines 591 to 710 of docs/FEATURESET.md (old name: savi). It continues featureset-part-3.md. The streams cover client/core rendering modules of spoint (read-only at d5e3860), which have no mention in cleetus's docs or scripts. Each line gives the path and line of the first export, re-read through git show d5e3860. Line counts are wc -l. Export counts are the ^export lines. A module counts as covered only when a witness script names it and prints a RESULT line. An importer that is itself a module, or a script that only reads source text, is disclosed as an importer and is not coverage. The spoint rows these streams feed are jayzee row 39 (client rendering, shadows, post-fx and grass), row 40 (editor, hot reload and HUD) and row 59 (client rendering and tools). See jayzee-gaps.md.

Later pages are featureset-part-5.md and featureset-part-6.md for lines 711 onward.

Decisions

  • A module is covered only when a witness script names it and prints RESULT, which is the check rule the stream uses (exit 0 with RESULT: PASS). Importers and source-text reads are disclosed and not counted.
  • Held files (OcclusionPolicy, OcclusionQueryBudget) are accepted as covered by a per-file entry, because the family-level prose was judged too loose.
  • Two scripts that import a copy rather than the module (the veg-lod stream control) are not counted as exercising the module.
  • Each stream gives wc -l totals so a reader can verify size, and states which exports were counted.
