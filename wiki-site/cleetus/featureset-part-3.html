Featureset part 3: streams 26 to 34

How it works

This page covers lines 361 to 590 of docs/FEATURESET.md (old name: savi). It continues featureset-part-2.md and is followed by featureset-part-4.md. Every stream is a read-only survey of spoint at d5e3860. Each citation is path and line, with the snippet found there, re-read through git show d5e3860 before the section was written. The survey narrows the tracked files of a directory by removing those already covered by another stream, and then records the remainder. Negatives are recorded as the grep that produced them. Nothing was written into spoint. The gate scripts/check-featureset.mjs (old name: savi) repeats the scans for these streams.

The sections on this page are the src/behaviours, src/apps, ServerBoot and StaticCache, chartState migrators, client HUD, procgen, effects, physics, shared, and bin modules. Their rows are in jayzee-gaps.md (rows 19, 23, 24, 26, 32, 39, 40, 51, 53, 54, 55 and 57).

Decisions

  • Each stream narrows its set by an explicit rule (remove files covered by another stream, remove files with a cleetus basename hit, remove files with a witness), so the scope of each survey is stated and reproducible.
  • A module is "covered" only when a witness script names it. Importers that are bake scripts or harnesses are disclosed as importers and not claimed as witnesses (GLBLoader, GLBMath, and the editor's ProcgenPanel).
  • Negatives are measured with git grep at the pin, and the section says which grep produced each one.
  • Where cleetus's docs mention a module only as an importer or in a directory list, the mention is disclosed, not counted as coverage.
  • Line totals are wc -l counts, and where two counts disagree (the editor's 5284 versus 5950 lines), the section says which scope reproduces.
