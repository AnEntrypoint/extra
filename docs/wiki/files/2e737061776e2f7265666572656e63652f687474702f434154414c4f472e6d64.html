# Jayzee HTTP door catalog

Sources: `me.doors` (GET https://www.jayzee.co/api/agent/v1/me, 60 entries, read with the lanmower token), `llms.txt` (no auth), and `api-types.md` (the full body of GET /api/agent/v1/api). Status legend: `exercised` = a GET run in this pass (Bearer and/or no-auth, see per-door file); `documented, not exercised` = not called, method and path quoted from the source text. No POST, PUT, PATCH or DELETE was sent.

Keys in the table are the names in `me.doors`. `me.doors` gives URLs only, so methods come from the docs text.
