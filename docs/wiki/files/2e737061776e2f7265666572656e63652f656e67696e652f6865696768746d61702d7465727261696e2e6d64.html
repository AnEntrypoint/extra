# Heightmap Terrain

`heightAt`/`materialAt` in your `scripts/terrain.js` are the landform (`jayzee api TerrainHeightmapDef`); `terrain.marks` are everything with an edge, overriding the generator. `heightAt` runs ~17k times per 80 m chunk: a track or a river is a mark, never a loop over points.

```js
// scripts/terrain.js; materialAt's ctx adds worldHeight (after marks and strokes), slope (1 − normal.y; 0.29 = 45°), height01, normal
import { shore } from "builtin/terrain";
const SEA = 0;
const clamp01 = (v) => Math.min(1, Math.max(0, v));
export function heightAt(ctx) {
  const { x, z, noise, seedOffset } = ctx; // always set frequency (default 1 cycle/m); ridged and billowed2 are ≥ 0 and sum their octaves (1.875 at the defaults)
  const r = Math.hypot(x, z), far = clamp01(r / 1500) ** 2;
  const land = far * (220 + 55 * noise.fbm2({ x, z, frequency: 1 / 900, octaves: 2, seed: seedOffset(0) }));
  const toSea = clamp01((z - 60) / 120); // −14 m seabed to the south
  return shore((20 + land * clamp01(r / 30 - 1)) * (1 - toSea) - 14 * toSea, SEA);
}
export function materialAt(ctx) {
  const { worldHeight, slope, noise, x, z, seedOffset } = ctx;
  const n = noise.fbm2({ x, z, frequency: 1 / 30, octaves: 3, seed: seedOffset(5) });
  if (worldHeight < 1.8 + n) return { sand: 1 };
  const rock = clamp01((slope - 0.25 + n * 0.1) * 4);
  return worldHeight > 200 + n * 20 ? { snow: 1 - rock / 2, rock: rock / 2 } : { rock, grass: 1 - rock };
}
```

The sea is `t.marks.sea = { kind: "sea", level: 0, floorMaterial: "sand" }` (`t = place.terrain`): water stands where `heightAt` < 0; the seabed is yours. Every coast passes through `shore(height, SEA)`, except a cliff. A lake fills your basin or digs a 2 m bowl (`depth: 0` never digs); a river runs downhill along its points to the sea or lake, `depth` digging its channel. A scripted `liquid.material` on the mark replaces the whole native look; keep its foam, caustics and fresnel as nodes from `jayzee api builtin/water`. A `material: { kind: "water" }` plane is a picture: nothing swims. Every edit is live for every player.

`t.materials.sand = { albedo: "cdn/texture-terrain-sand-realistic-albedo.png", tint: "oklch(0.82 0.06 80)", textureScale: 2 }`: ground wears PBR by default, a CDN picture named like the fresh world's grass, gravel and rock (keep them). A painted `scripts/tex-*.js` is drawn ground (relief from its brightness, no roughness map) and a tint alone is flat painted ground: each only on a creator's ask. Add any other id whole or its weight paints nothing. Cover: `t.decorations.layers.<id>` + `bindings.<materialId>: [layerId]`: a layer grows only where a binding material dominates; `t.decorations = null` removes it all. Nothing grows under a thing on the ground (a floor, a deck, a trunk) or on a `path` or `road` unless a stroke paints its layer there; a `clear-scatter` mark suits open ground. `density`: items/m² of bound ground (starter meadow 50, stubble 3). Cover ends where its item draws 2 px wide, within its and the settings' `maxDistance`. Meadows:. A verge is a layer bound to the path's `edgeMaterial`.

`t.material = { kind: "scripted", script, params }` shades all ground with `material(ctx)`.

A bed on an uploaded or built mesh floor names it in `scatter.surface.mesh`: instanced cover; `filter.maxSlope` its slope cutoff. Path posts are one scripted object (→geometry), never a bed: a `ctx.instance` per step along `points` at `ctx.groundY`.

A graded path is a `path` mark with `grade: true` or a `road` with `spline` (`points` only paint), never `materialAt`; the walk controller refuses slopes past 45°.

Ground detail reach is that viewer's graphics tier: low anywhere and medium on phones and tablets stream the near bands, medium elsewhere, high and ultra append farther, coarser bands, coarse ground to `camera.clip.far`. On coarse far ground, read their `graphics tier:` first (`jayzee perf --frame`, player-settings skill).

Sculpt, dig and material paint are field paint: `terrain.stroke(field, { center, radius, fn })`, `fn(p, inset, current)` the cell value. A hook's dab is this room's (PLAYER layer, never your files), takes any radius (~1 ms at 11 m), reaching others a few ticks later; a `run_script` that persists, a god-mode brush or `.authored` write paints the CREATOR layer's chunk files that publish takes. `delete ctx.place.terrain.runtimeEdits` drops the PLAYER layer, restarts included. A material's weight adds to natural ground (1 is about half the cell); `"terrain:natural-mask"` at 1 lays the paint alone. A rut, crown, ditch or bank is `"terrain:height"` strokes along the mark's points.

Water is field paint too: `"terrain:water"` is metres of water over ground (0 dry): a level pond paints `level - terrain.heightAt(p.x, p.z)`, a channel its depth; the engine draws it and bodies swim.
