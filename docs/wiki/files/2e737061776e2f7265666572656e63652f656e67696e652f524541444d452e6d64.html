# Jayzee engine 6.0.0 — the vocabulary

Read-only, published by Jayzee's CI from the build that shipped this version. A 6.0 world's
`.jayzee/engine.yaml` names this repo; clone it shallow into the world
(`git clone --depth 1 <this url> .jayzee/engine`, gitignored) with the same token.

- `api-reference.md` — the supported game API for this version.
- `skills/<id>.md` — the engine-use guide (`jayzee-engine`) and the skills this version publishes for agents, whole; `skills.md` is the index.
- `engine.yaml` — the pin and the engine build's sha256.
