## Kinds of URL seen on the pages [verified]

- https://jayzeefile.io/dev/jayzee-clips/v1/<worldId>/seo-preview/publish-<uuid>/value.<sha256>.webp : content-addressed preview images per publish. 93 such URLs, every value name is 64 hex (sha256 length).
- https://jayzeefile.io/dev/character-assets/<unix-ms>-<uuid>.glb : per-project character GLB, named by timestamp and uuid, not by hash.
- https://www.jayzee.co/magic/character-character-<id>.glb : 302 to https://jayzeefile.io/dev/magic-assets/v5/values/<sha256>.glb?_av=raw1 (the path hash is the bytes' sha256).
- https://jayzeefile.io/dev/trophies/<hex>-... : trophy images (no extension), 50 on one page.
- Download binaries (.dmg, .exe) linked from every page: not downloaded.
