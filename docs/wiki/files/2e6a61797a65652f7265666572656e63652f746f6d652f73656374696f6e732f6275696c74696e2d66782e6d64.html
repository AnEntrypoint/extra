## builtin/fx

Export effect(ctx) from the effect script. Return fx(...populations). jayzee rate is particles per second. lifetime, delay, and window use seconds; size uses meters; rotation uses radians. alpha is 0 to 1. World space is the default. An omitted lifetime does not expire. The effect ends when its owner is removed, or call ctx.destroy(id). A sprite with align: "ground" lies flat on the face attr("normal") names, so a ripple ring or a stamp lies along the slope or wall it hit, with no axis. parent(name) is a when() child's live read of its jayzeeing parent each tick: "p", "v", "age", "life", "size", "rand", "localP", "normal" or the parent's own attribute; a dies child reads its parent as it died.
