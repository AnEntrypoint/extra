# Engine overview: the jayzee engine notes (cleetus workspace)

## How it works

The directory /workspace/savi/spawn-engine/ (old name: savi) is a set of read-only research notes and two data files about the jayzee engine (old name: spawn) and the public projects built on it. Every note was produced by GET or HEAD probes, docs-door reads, and the client join log. Nothing was written to a world. Each claim carries a tag: [verified] means read live or seen in the client log, [documented] means taken from the public spec, llms.txt, a docs door, or a skill door, [observed] means seen once in a log with the cause unknown, and [inferred] means reasoned from names or logs.

The files, grouped by what they describe:

### Projects and the public feed

- /workspace/savi/spawn-engine/PROJECTS.md (old name: savi). Lists the 22 projects on the first feed block (all engine 6.0.0) with owner, world_id, app_id, engine, plays and likes, plus the two projects the account owns: game-10 (world 82462294-897e-4906-8405-1513baea875d, app be1ff78b-d465-4688-aa20-b5ff8b5737df) and the-savi-gallery (world 26f64424-cc19-43af-a9c3-666e4559bb05, app d21d322b-4572-4710-a8d5-eaef4e6daa1f). It states that the feed record fields used are games.name, games.world_id, games.engine_version, app_id, profiles.username, play_count and like_count. It lists the folio parts of the-savi-gallery (weights, card:story, community, direction, hero, journey, look, moments, posts, slices, story, themes, card:first_review, weigh:<id>, update:<id>) and the art URL form https://spawnfile.io/dev/launch-kit/<appId>/<name>-<16 hex>.png. It records the access results for other projects' folios (403 not_your_kit), docs doors (403 "No access to this game" for other worlds, 401 anonymous), and manifest/health paths (404 and 403). Its correction note points to FEED_SCOPE.md for the full list.
- /workspace/savi/spawn-engine/FEED_SCOPE.md (old name: savi). Describes how the public feed was walked: GET https://www.spawn.co/api/feed?offset=<n>, stepping offset by 22 until two empty pages in a row. page= and cursor= are ignored, and limit=100 returns at most 44 rows. The walk found 3421 distinct projects across 66 engine versions. 2853 are on 6.0.0. The most common versions after 6.0.0 are 0.1.0 (107), 5.2.34 (40), 5.2.4 (28), 5.2.40 (26), 5.2.21 (25), 5.2.39 (21) and 5.2.3 (14). The file records that the-savi-gallery (app d21d322b-4572-4710-a8d5-eaef4e6daa1f) appears on feed offset 176 with 19 plays and 3 likes, and that game-10 is absent because it is unpublished [inferred].
- /workspace/savi/spawn-engine/data/feed-projects.json (old name: savi). A JSON array of 3421 objects, one per project from the feed walk, with the keys app_id, world_id, name, owner, engine, plays and likes. The app_id values are unique (no duplicates). It holds 66 distinct engine strings. The first record is Escape from Stranglethorn (app c52c8aab-4429-4dc4-83df-951cf88227f1, izkimar, engine 6.0.0, 88225 plays, 575 likes). The file is about 625 KB.

### Asset inventory of public pages

- /workspace/savi/spawn-engine/PROJECT_ASSETS.md (old name: savi). Method: GET https://www.spawn.co/@<owner>/<slug> for the 22 first-block projects (slug = games.adventure_name; two slugs, world-of-spawncraft-2 and game-8, differ from the feed names). All 22 returned 200. Each HTML page was grepped for spawnfile.io, www.spawn.co/magic and kiln.spawn.co URLs. The table gives, per project, distinct URLs, GLB count, character webp count, clip-preview webp count, MP4 count, PNG/JPG count, trophy URL count and download link count (dmg/exe, not downloaded). The total is 395 distinct URLs after stripping the query string. It lists the URL kinds seen: content-addressed preview images under spawnfile.io/dev/spawn-clips/v1/<worldId>/seo-preview/publish-<uuid>/value.<sha256>.webp (93 URLs), per-project character GLBs named by timestamp and uuid, www.spawn.co/magic/character-character-<id>.glb which 302s to spawnfile.io/dev/magic-assets/v5/values/<sha256>.glb?_av=raw1, and trophy images under spawnfile.io/dev/trophies/. It contains a content-address check table (GET then sha256sum) for five URLs, four matching by name and one non-content-addressed character GLB whose ETag equals the md5 of its bytes.
- /workspace/savi/spawn-engine/data/feed-asset-inventory.jsonl (old name: savi). 1693 JSON lines, one per project page fetched (every row has status 200). Keys per row: app_id, world_id, owner, slug, name, engine, status, bytes, asset_urls, assets. Each entry of assets has the keys url, ext and kind. The kind values and their counts across all rows are character 14495, other 6959, clip-preview 5694, magic 1743 and trophy 130. The file is about 4.7 MB. It is a superset of PROJECT_ASSETS.md, which covers only the 22 first-block projects.

### Engine manifests and client builds

- /workspace/savi/spawn-engine/MANIFESTS.md (old name: savi). Covers four manifest kinds. (1) The engine client manifest: GET https://www.spawn.co/api/client/manifest returns 302 to https://www.spawn.co/v4/client/<engine>/agent/manifest.json. Its shape is version (1), cli ("spawn.mjs"), files (spawn.mjs, session-lib.mjs, main.mjs, browser-client.mjs, each with a sha256-<base64> SRI value) and bun.floor ("1.4.0"). A table records the redirect target over time: e8641edd3e95e30ff487e8423fb41dff early, b7a5a3451fe996f116985ac743c91eae later, and e66271e15431f09c7eaa8f46eafcd5d8 latest. (2) The world room manifest, per world per boot, seen only in the join log by its hash (f3481c28177c...). Candidate GET paths all return 404 not_found. (3) The docs door: GET https://www.spawn.co/api/sdk/v1/{W}/agent/docs returns appId, engineVersion, era, playUrl, gitUrl, codeUrl, specVersion, guide, tomeApi, sections (68 headings) and skills (23 ids). Each section can be read with ?section=<heading>. Each skill is read at /agent/skills/<id>. The skill ids are spawn-engine, 2d-mode, buyables, cameras, fx, game-ui, geometry, heightmap-terrain, interactive-objects, jev, leaf-sprays, mobile-controls, physics, platform-systems, player-settings, pointer-raycasting, portals, projectiles, rooms-and-matchmaking, trees, uploaded-models, vehicles, voxel-terrain. (4) The git tree, described in GIT_HOST.md. A cross-project table compares the four reads for our two worlds and the six other worlds tested.
- /workspace/savi/spawn-engine/FAULTS.md (old name: savi). A numbered fault log with reproduction steps and evidence. F1: GET https://www.spawn.co/api/games/{appId} answers 200 with game: null for every app id, including the owner's own game, and the route is absent from the published spec. F2: the first two client joins stopped before the world because the bundled Playwright browser (chromium_headless_shell-1248) was missing; the local fix was a Playwright install into the client cache, which wrote no Spawn data. The third join succeeded, and the body was listed as claude_haiku_55. F3 [observed]: the asset ledger read returned "no head this copy heard carries it" for two world.assets/ rows during boot, and it did not reproduce on demand. F4: the games door returns playUrl under @claude_haiku_55 while the me/worlds doors return @lanmower. F5: the no-query client manifest pointer changed its target between two reads, differing only in browser-client.mjs. A "Not faults" section lists expected answers (assets PUT-only 405, other worlds 403, not_your_kit 403) so they are not re-reported.

### Assets, shapes and the git host

- /workspace/savi/spawn-engine/ASSETS.md (old name: savi). Covers the GLB and texture asset path for the engine at version 6.0.0. Write path: PUT https://www.spawn.co/api/sdk/v1/{worldId}/assets/value.<sha256>.<ext> with a Bearer sak_ token and the raw bytes. It answers 201 with { url } when new and 200 "exists" when the bytes are already carried. A name that does not match the content is 422 content_mismatch, a Content-Type that disagrees with the extension is 415, and a body over 4.5 MB is 413. Larger files use three steps: POST .../assets/upload-target {name, sizeBytes} returns {uploadUrl, tempPath}; the bytes are PUT to uploadUrl; then PUT the value name with {"tempPath": ...}. A GLB's textures must ride inside or beside it, or the server returns 400 external_references. Editor standing is required. Tree references take the form /cdn/value.<sha256>.<ext> (or cdn/<name>, for example cdn/fountain.glb). Read path: there is no GET door for a carried asset (GET on value.<64 zeros>.glb returns 405), and the bytes are served from the CDN on spawnfile.io. The live client load path from the game-10 join log is listed in six steps, with the URL forms, the HEAD headers of a live GLB (content-type model/gltf-binary, content-length 64699780, etag md5-shaped) and the statement that prod character GLB names are not content hashes. Textures: no texture manifest was found, and texture rows were not seen in the ledger log.
- /workspace/savi/spawn-engine/ASSET_SHAPES.md (old name: savi). Source: GET https://www.spawn.co/api/agent/v1/api?type=<Type>. It lists 308 types in total (from the type list) and 20 asset-related type names, then gives the TypeScript-style shapes: AssetMetadata (boundsVersion, triangles, skinned, clips, gait, gaitVersion, bounds {min,max,size,center}, sockets, parts, partsVersion, sprite2d, duration, kind, name, uploadedAt, bytes); AssetPartEntry (center, size, groundOffsetY?, tris, confidence, version); AssetSocketEntry (position, groundOffsetY, bone?, boneOffset?, confidence, version); AssetSprite2DEntry (version, meta) and Sprite2DMetaSpec (outline, world_height, target_size, style "pixel" or "non-pixel", kind "sprite" or "texture", anchor_uv, view, content_box); StandardMaterialSpec with CDN-name texture fields (texture, normalMap, roughnessMap, metalnessMap, alphaMap, emissiveMap), pbr, repeat, textureScale, wrap, filter and scalar fields; ScriptedMaterialSpec (kind "scripted", script, params); MaterialSpec as a union with { kind: "water" }; TextureScript with texture(ctx) and meta; ModelPartStateSpec (material plus visible flag); VoxelMaterialDef (color, texture CDN name, pbr, roughness, metalness, collision "solid" or "none", blockBehavior and others). The file notes that no GET door returns an AssetMetadata record.
- /workspace/savi/spawn-engine/GIT_HOST.md (old name: savi). Host https://git.spawn.co/@<owner>/<slug>.git. Anonymous GET returns 401 with the message that HTTPS basic auth with the same username and token is needed. Basic auth as claude_haiku_55 gets 200 for game-10 info/refs, and 404 for other projects (the host does not distinguish private from missing worlds). The game-10 info/refs answer lists HEAD and refs/heads/main at d6c3dcc331fb9a83b1c376140e7b8ade22fde3aa, refs/notes/spawn at 10a82f3eef3ee60e9fdb9ed438d0a24c9d13dc9b, and the capabilities list (multi_ack_detailed, side-band-64k, thin-pack, ofs-delta, shallow, filter, symref=HEAD:refs/heads/main). The commit matches the join welcome. Dumb HTTP paths (HEAD, objects/info/packs) return 404 even with auth, and a tree read needs the smart protocol POST, which was not sent.

## Open gaps

- Textures have no manifest, and no texture row was seen in the ledger log. Source: /workspace/savi/spawn-engine/ASSETS.md (old name: savi).
- The world room manifest body cannot be read by any GET door tested; a door outside the spec is not ruled out. Source: /workspace/savi/spawn-engine/MANIFESTS.md (old name: savi).
- The ledger rows for two world.assets/ entries were not confirmed as settled after catch-up. Source: /workspace/savi/spawn-engine/FAULTS.md (old name: savi), F3.
- Where AssetMetadata is stored, and whether any live record matches the type, is not verified. Source: /workspace/savi/spawn-engine/ASSET_SHAPES.md (old name: savi).
- The mapping from a full prod GLB URL to its lodpack is inferred, not read from an endpoint. Source: /workspace/savi/spawn-engine/ASSETS.md (old name: savi).
- The complete asset list of other projects is not reachable with the token used; the inventories are floors. Sources: /workspace/savi/spawn-engine/PROJECT_ASSETS.md (old name: savi), /workspace/savi/spawn-engine/GIT_HOST.md (old name: savi).
- The cause of the games route returning game: null (F1) is not known. Source: /workspace/savi/spawn-engine/FAULTS.md (old name: savi).
- The cause of the no-query manifest pointer moving (F5) is not known. Source: /workspace/savi/spawn-engine/FAULTS.md (old name: savi).
- PROJECTS.md still describes only the 22 first-block projects; its correction note defers to the full list. Source: /workspace/savi/spawn-engine/PROJECTS.md (old name: savi).
