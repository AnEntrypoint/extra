How it works

Every run directory under /workspace/spawn/runs (old name: spawn) is listed below in creation order. The date and time are createdAt from task.json, in UTC. The outcome is taken from the run's own files: for a run with an end event it is the finished witness in that event (log.jsonl), and for a run without one it is the last event in log.jsonl. Outcomes are one line each, and every figure in them comes from the run's log. Full witnesses and gaps are in runs-open-gaps.md, and decisions are grouped by theme in runs-findings.md.

Decisions

The outcome for each run is the witness its own end event recorded, so no outcome is inferred across runs. Where a run's outcome records a choice (for example a push that was reverted, a route that was held for the owner, or a standby), that choice is set out with its evidence in runs-findings.md. A run that has no end event is listed with its last logged event, not with an assumed result.

Open gaps

The 20 runs with no end event are listed in section 1 of runs-open-gaps.md. Each open item that a finished run's witness recorded is listed there, under its theme, with its run id.
